# Lab 03: Machine Learning Workflow and Learning Types

## Overview

This lab introduced the complete machine learning workflow and the three primary categories of machine learning: supervised learning, unsupervised learning, and reinforcement learning. Using the Wine dataset, I explored the steps involved in preparing data, training models, evaluating performance, and interpreting results.

The lab also reinforced the importance of understanding data before building models and demonstrated how different machine learning techniques are applied to real-world problems.

---

## Objectives

By completing this lab, I learned how to:

* Distinguish between supervised, unsupervised, and reinforcement learning.
* Understand the complete machine learning workflow.
* Perform exploratory data analysis (EDA).
* Prepare data for machine learning.
* Split data into training and testing sets.
* Train classification models.
* Evaluate model performance using appropriate metrics.
* Relate machine learning concepts to real-world applications.

## What I Learned

One of the biggest lessons from this lab was that building a machine learning model is a structured process rather than simply choosing an algorithm. Each stage, from understanding the problem to evaluating the final model, contributes to producing meaningful and reliable results.

I also developed a stronger understanding of when different learning approaches are appropriate:

* **Supervised Learning** uses labeled data to make predictions.
* **Unsupervised Learning** discovers patterns in unlabeled data.
* **Reinforcement Learning** improves decisions through rewards and feedback over time.

---

## Challenges

A challenge during this lab was understanding how each stage of the machine learning workflow connects to the next. It became clear that poor data preparation or feature selection can negatively affect model performance, regardless of the algorithm used.

Comparing different learning types also required careful consideration because each approach is designed to solve different kinds of problems.
