# Lab 02: Tools Used in Machine Learning

## Overview

This lab introduced the software tools and Python libraries commonly used throughout the field of machine learning. The objective was to become familiar with the development environment while practicing the basic workflow of loading data, exploring a dataset, creating visualizations, and documenting work using Markdown.

The Iris dataset was used as the first machine learning dataset to demonstrate data exploration and simple analysis techniques.

---

## Objectives

By completing this lab, I learned how to:

* Use Google Colab as a machine learning development environment.
* Import essential Python libraries.
* Load a dataset using Scikit-learn.
* Convert data into a Pandas DataFrame.
* Explore dataset structure and summary information.
* Create basic data visualizations using Matplotlib.
* Perform simple statistical analysis.
* Practice writing documentation with Markdown.
* Understand the role of GitHub in organizing machine learning projects.

## What I Did

During this lab I:

* Imported the required Python libraries.
* Loaded the Iris flower dataset from Scikit-learn.
* Converted the dataset into a Pandas DataFrame for easier analysis.
* Explored the dataset by viewing its structure, features, and sample records.
* Created a scatter plot comparing sepal length and sepal width for each Iris species.
* Calculated descriptive statistics, including the mean and standard deviation of sepal length.
* Created a bar chart showing the distribution of flower species.
* Practiced documenting observations using Markdown.

## What I Learned

This lab demonstrated the typical workflow followed at the beginning of many machine learning projects. Before building models, it is important to understand the dataset, inspect its structure, visualize patterns, and calculate summary statistics.

I also learned how several Python libraries work together:

* **NumPy** performs numerical calculations.
* **Pandas** organizes and analyzes data.
* **Matplotlib** creates visualizations.
* **Scikit-learn** provides datasets and machine learning tools.

---

## Challenges

One of the main challenges was becoming familiar with the different Python libraries and understanding when each one should be used. Although they work together, each library has a different purpose.

Learning how datasets are loaded from Scikit-learn and converted into a DataFrame also helped me better understand how machine learning projects are organized.

## Results

The Iris dataset contained:

* **150 flower samples**
* **4 numerical features**
* **3 flower species**

The visualizations showed that the three species exhibit different measurement patterns, illustrating why the dataset is commonly used as an introductory classification problem.

The statistical calculations and visualizations provided an initial understanding of the data before applying machine learning algorithms in future labs.
