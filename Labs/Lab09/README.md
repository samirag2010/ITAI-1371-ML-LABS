# Lab 09: Ensemble Methods

## Overview

This lab introduced **ensemble methods**, a machine learning approach that combines the predictions of multiple models to produce more accurate and reliable results than a single model. Using the Iris dataset, I compared the performance of a single Decision Tree classifier with a Random Forest classifier to understand the advantages of ensemble learning.

The lab also explored feature importance, demonstrating how Random Forest models can identify which features contribute most to making accurate predictions.

---

## Objectives

By completing this lab, I learned how to:

* Understand the concept of ensemble learning.
* Explain why combining multiple models often improves performance.
* Train a Decision Tree classifier.
* Train a Random Forest classifier.
* Compare the performance of individual and ensemble models.
* Interpret feature importance scores generated by Random Forest.

## What I Learned

This lab demonstrated that combining multiple machine learning models often produces better predictions than relying on a single model. A Random Forest reduces the risk of overfitting by averaging the predictions from many Decision Trees, resulting in improved accuracy and better generalization to unseen data.

I also learned that feature importance provides valuable insight into which variables have the greatest influence on model predictions, helping improve both model interpretation and future feature selection.
