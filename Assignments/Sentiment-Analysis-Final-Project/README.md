# Sentiment Analysis Final Project

## Overview

This project represents the culmination of everything learned throughout **ITAI 1371: Introduction to Machine Learning**. The objective was to develop a complete end-to-end machine learning workflow 
capable of analyzing customer sentiment from text reviews.

From selecting a dataset to evaluating multiple machine learning models, this project demonstrates the full lifecycle of a supervised machine learning project using natural language processing (NLP) techniques.

---

## Problem Statement

Businesses receive thousands of customer reviews every day, making it difficult to manually understand customer opinions and identify trends. The goal of this project was to build a machine learning model 
capable of automatically classifying customer reviews according to their sentiment.

By automating sentiment analysis, organizations can better understand customer satisfaction, identify common concerns, and make more informed business decisions.

---

## Objectives

- Select an appropriate public sentiment analysis dataset.
- Perform exploratory data analysis.
- Clean and preprocess textual data.
- Convert text into numerical features using TF-IDF.
- Train and compare multiple classification models.
- Evaluate model performance using standard classification metrics.
- Interpret the results and discuss possible improvements.

---

## Methodology

The project followed a complete machine learning workflow:

1. Dataset selection
2. Data exploration
3. Text preprocessing
4. Feature extraction using TF-IDF
5. Model training
6. Model evaluation
7. Performance comparison
8. Interpretation of results

Two machine learning classification models were trained and evaluated to determine which produced the best performance for sentiment classification.

---

## Results

The trained models successfully classified customer reviews based on sentiment. Model performance was evaluated using metrics such as:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

The comparison highlighted the strengths and limitations of each algorithm while demonstrating how preprocessing and feature engineering influence model performance.
