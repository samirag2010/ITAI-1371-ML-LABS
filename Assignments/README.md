# Assignments

This folder contains the major assignments completed throughout the Introduction to Machine Learning course. Each assignment includes a dedicated README describing the project objectives, methodology, results, and key lessons learned.

## Contents

- **Final Project** – An end-to-end machine learning project demonstrating the complete ML workflow from data preparation to model evaluation.
- **Responsible AI Assignment** – A presentation-based project exploring the ethical design of AI through *Spartacus Dental AI*, focusing on fairness, privacy, transparency, accountability, and societal impact.
